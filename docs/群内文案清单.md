# 群内文案清单

> **用途**：改群消息文案时的总入口，也是「这句话在哪儿」的索引。
> **唯一事实来源是代码** —— 本清单是索引与现状记录，改完代码请回来同步这里。
> 核对日期：2026-10-10 晚（含 `fw付款` / `fw取消订单`、传截图措辞统一、逐条换行整理、
> `me` 的月卡行支持 STAFF 卡显示「长期有效」）
>
> 文中 `{…}` 是运行时填进去的占位符；`\n` 表示换行。

## 0. 先读这几条规则

| 规则 | 说明 |
| --- | --- |
| **文案几乎全在 `QqReplyText`** | 该类纯静态、无状态，可脱离 Spring 单测。**例外三处**：`QqBroadcastListener`（到店 / 离店播报、@ 段的组装）、`user/QqVerifyService.ConfirmResult`（验证码回执三条）、`QqWriteCommandService`（`NO_BROADCAST_HINT` / `WRITE_DISABLED_HINT` 两句） |
| **命令行不带句号** | 回复里以指令结尾的那一行**不写「。」**：用户长按复制整行就能直接发出去，带上标点过不了解析器的整条匹配，表现为「没认出这条指令」 |
| **一行一件事** | 事实一行、每条下一步动作一行、URL 跟着它的说明。2026-10-10 由用户要求逐条整理 |
| **金额受开关管** | 当事人自己问的（`fw看看自己` / `fw结账` / `fw付款`）受 `uspace.qqbot.self-amount-visible` 管；系统主动推的播报按群分级（`isAmountVisible`）。改文案时别把金额写到不受管的那一侧 |
| **@ 之后换行** | 所有 @ 都由 `OneBotAction#sendGroupMessageWithAt` 在 at 段与正文之间加 `\n`（2026-10-10 由用户要求）。⚠️ **正文不要以空格开头** —— 那是换行统一之前的旧写法（用前导空格给 @ 留缝，`proofRejected` 曾如此），现在只会变成新行开头的多余缩进 |
| **回复有节奏** | 指令回复经 `QqReplyQueue` 限速发出：**每条前等 3~10 秒随机、含第一条**（2026-10-10 由用户要求，防 QQ 风控）。测试与排障时别以为机器人卡了；`fw开门` / `fw结账` 直发、不受限 |

### 共用常量（改一处 = 改一片）

| 常量（`QqReplyText` 内） | 现值 | 用在哪 |
| --- | --- | --- |
| `PAY_SCREENSHOT_TEXT` | `在五分钟内发送带交易单号的付款凭证截图到群内。` | 所有受理截图的地方 |
| `PAY_SCREENSHOT_ALSO` | `也可以` + 上一句 | 前面刚给过「网页付款：\<url\>」的那几处 |
| `PAY_SCREENSHOT_AFTER_ARM` | `也可发送 fw付款，之后` + `PAY_SCREENSHOT_TEXT` | 闸还没撑起来、要先发指令的那几处 |
| `PAY_WINDOW` | `五分钟内` | 上面两句，以及 `screenshotExpired` |
| `NOT_BOUND` | `该 QQ 尚未绑定账号。请先在网页端注册并完成 QQ 验证，之后即可使用。` | 所有指令的未绑定分支 |
| `UNKNOWN_COMMAND` | `无法识别该指令。可发送 fw帮助 查看可用指令。` | 认不出指令时 |

⚠️ **只改 `PAY_SCREENSHOT_TEXT` 那半句，不要各写一份**：它同时出现在 6 处回复里，
时限还与 `QqPaymentProofService.WAIT_WINDOW`（5 分钟）绑定 —— 两边不一致时
用户没有任何办法看出来。

## 2. 写指令

| 正常 | `openPasscode` | `门锁密码：{6 位}\n该密码仅可使用一次，请勿转发。\n固定密码已通过私聊发送，如未收到请前往网页端查看：{url}`（私聊开关关掉时第二句换成 `如需可重复使用的密码，请前往网页端查看：`）；已在计时中时开头多一行 `你已在计时中（{时长}）。` |

### 2.5 截图那条路本身

| 写指令总开关关着 | `QqWriteCommandService` | `WRITE_DISABLED_HINT` |
| 连点 | `checkAllowed` | `操作过于频繁，请 {N} 秒后重试。` |
| `fw帮助` | `help` | 分组列出可用指令（写指令关掉时那一组整段不列；库存/机台两条只对管理员列） |

## 5. 「文案住在哪儿」速查

| 类 | 负责 |
| --- | --- |
| `QqReplyText` | **绝大多数文案**：指令回复、播报、兜底 |
| `QqBroadcastListener` | 到店 / 离店两条播报的抬头与正文（含金额分支）、@ 段的组装 |

| `user/QqVerifyService` | 验证码回执三条 |
| `QqWriteCommandService` | 播报未开 / 写指令未开两句常量 |
